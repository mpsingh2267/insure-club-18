Cloud Connection & Mode

InsureClub operates in Local Sandbox Mode (zero network setup, saved in browser) or connects directly to your live Supabase PostgreSQL cloud instance.

1
Create Free Supabase Project
Visit supabase.com and create a free project (ready in under 60 seconds).
2
Execute InsureClub Schema in SQL Editor
Open the Supabase SQL Editor and run our pre-built schema to create all tables (customers, policies, family, documents, appointments, reminders) and RLS security policies.
3
Connect & Push Data
Paste your Project URL & Public Anon Key below, click Test Connection, and optionally push all current sandbox clients and policies straight into your live database.
