# InsureClub Premium CRM 2.0

Install `InsureClub-Premium-v2.0.apk` directly over version 1.0 to retain existing local data. Both builds use the same signing certificate. Android 8.0 or newer is required.

The upgrade adds connected customer profiles, family birthdays, active-policy/history renewal workflow, policy PDFs, advanced search, appointments, porting, editable message templates, premium dashboards, a full reminder centre, automatic safe backups, complete export, validated import, and restore.

Important:

- Do not uninstall the old app before upgrading if it contains real data.
- Allow notifications after opening version 2.0.
- Use Settings → Backup & Restore → Export complete data to keep an external `.icbackup` copy.
- WhatsApp messages are personalized and prepared by the app, but you remain responsible for pressing Send.
- Uninstalling the app or clearing app storage removes local data unless it has been exported.
